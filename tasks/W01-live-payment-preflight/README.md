Backend routes:
- POST /api/lessons/{id}/live-checkout: current verified student bearer token, exact web Origin, Idempotency-Key (16–128 safe characters), X-Student-Creators-Terms-Version (approved terms version), empty body. Price and order identity are server-controlled. Returns an order ID and trusted Paystack checkout URL only after durable reservation and rechecking current access.
- POST /api/webhooks/paystack-live: documented raw-body x-paystack-signature (live API key), optional v1 signing keys, live-only charge.success, refund.processed and dispute lifecycle events; durable inbox before acknowledgment. Reference-only refund notifications are supported, verified by Paystack transaction and refund list reads. Partial refunds and disputes require review.
- node scripts/process-live-paystack-charge.mjs: independent Paystack verification, leased settlement, immutable journal, expiring entitlement, and reversal reconciliation; callable after checkout disabled.
