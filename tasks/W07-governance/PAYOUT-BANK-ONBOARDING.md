# Creator bank account provider foundation

This server-only read adapter follows Paystack's documented bank list, resolve account, and fetch transfer recipient APIs: https://paystack.com/docs/api/miscellaneous/ and https://paystack.com/docs/api/transfer-recipient/. It performs only GET calls. The live builder is explicitly disabled unless the new bank onboarding flag is set and existing production configuration is valid. No caller or route is wired yet; do not enable the flag as a substitute for authorization.

Remaining integration: actor-bound current student session, independent bank ownership/identity evidence and consent, durable rate limits, protected recipient creation/replacement with fresh resolution and independently authorized evidence, existing payout evidence lifecycle and lock coordination, masked creator status, audit trail without raw account numbers, and actual provider acceptance. Account name resolution does not prove ownership. A provider recipient code must never be trusted solely because a browser submitted it. Do not enable payouts or create real recipients as part of automated tests. Test fixtures are synthetic and not provider acceptance.
