# Week 1 hosted Auth lifecycle
Stacked on #50 current-session guard; depends on #55 Auth Send Email hook. Dedicated one-seat, founder-approved pilot invite only, no public signup. POST /api/hosted-auth/{invite,sign-in,refresh,logout,recover,complete}. Invite code is fixed private environment secret, one durable reservation before actual provider invite; no duplicate on uncertain network outcome. Sign-in/refresh use native Supabase Auth and current-session validation; access token returned to caller memory, rotated refresh token in Secure HttpOnly SameSite cookie. Logout reports unverified remote revocation rather than claiming success. Complete verifies provider OTP, sets password, globally revokes sessions before returning; OTP-derived session never returned. Minimal /auth/confirm form for provider email; Week 2 owns full hosted client onboarding.
Recovery returns generic DB-only 202 for known and unknown addresses. A separate explicitly enabled worker node scripts/request-hosted-recovery.mjs claims approved recipient jobs and calls native recover; uncertain provider request not repeated automatically. HMAC request digests, persistent limits and no raw email/credentials in tables. No provider sends or real accounts created by tests.
Requires explicit STUDENT_CREATORS_HOSTED_AUTH_ENABLED, STUDENT_CREATORS_SUPABASE_SIGNUPS_DISABLED_CONFIRMED (operator assertion, not proof), STUDENT_CREATORS_AUTH_EMAIL_ENABLED, STUDENT_CREATORS_PILOT_SEATS=1, STUDENT_CREATORS_PILOT_EMAIL, STUDENT_CREATORS_PILOT_INVITE_SECRET and separate STUDENT_CREATORS_HOSTED_AUTH_PEPPER; optional founder-controlled admin sign-in email. All usual dedicated staging gates and trusted origin. Enable recovery worker only after acceptance. Native provider settings must independently disable direct public/anonymous signup and enforce email OTP/rate limits; actual invite, OTP, password sign-in, refresh, recovery, global logout/session removal and direct API denials remain unverified.
Original source based on Supabase Auth API and email template documentation, no copied code or added dependencies. No live release.
