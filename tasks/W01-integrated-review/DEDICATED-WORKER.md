# Dedicated hosted worker
Run `node scripts/run-hosted-workers.mjs` on a supervised Node 22 Linux worker host with HTTPS egress to approved providers. Use a secret store or protected environment file; never place credentials in the repo or logs. Requires explicit background and dedicated worker enablement plus each provider's existing flags/config. Identity scan additionally needs an approved identity data policy, a private bucket and a functioning local ClamAV Unix socket. Use a service manager with restart-on-failure, non-root user, no public port, no writable repository and at least 90 seconds graceful shutdown. A tick is sequential, rotates queues, and uses durable database leases; no overlapping in-process ticks. Logs contain queue counts only; alert on repeated degraded ticks or no heartbeat. No production host or schedule has been activated. This worker scans identity files, not original direct-to-Mux video bytes; video playback continues to require a separately trusted clean verdict. Never infer a clean scan from a Mux-ready asset.
