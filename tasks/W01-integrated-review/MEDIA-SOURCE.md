# Private media source upload
Production direct Mux upload URL issuance is disabled. Backend contract: POST /api/lessons/{lessonId}/media-source with Bearer and JSON action reserve, mime, bytes, digest (SHA-256 hex). Use returned signed Supabase upload URL/token for immutable upload, then POST action complete with id. GET returns quarantine and provider status. Large videos should use Supabase resumable upload with the signed token. No client is given the Mux upload URL. The dedicated worker reads the exact bounded file, checks magic/size/digest, runs ClamAV and sends the same buffer to Mux only after a clean verdict. An uncertain provider create/upload moves to review rather than automatic repeat. The DB only marks the corresponding asset ready/clean after a trusted dispatch and exact Mux ready snapshot. Requires explicit media source policy, upload, worker and Mux live gates. No gate is activated. Dedicated ClamAV host must configure StreamMaxLength, MaxFileSize and MaxScanSize >=100 MiB, AlertExceedsMax yes, current signatures and adequate memory; validate real engine before enabling. No media retention/deletion policy is assumed. References: https://supabase.com/docs/guides/storage/uploads/standard-uploads and https://www.mux.com/docs/guides/upload-files-directly. Frontend agent must use this API rather than direct Mux.
