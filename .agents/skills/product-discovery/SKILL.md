# product discovery

## When to use
Use for related GitHub issues and features; this file is scoped guidance, not a granted external permission.

## Procedure
Read Teresa Torres Opportunity Solution Tree and Marty Cagan links in docs/EXPERT_ROLES_AND_OPEN_SOURCE_PLAYBOOK_2026-11-23.md. Establish desired product outcome, separate creator supply from viewer demand, gather only consented actual behavior and do not invent interviews. Map user problem -> opportunity -> hypothesis -> smallest test -> measurable result. Deliver an issue-scoped PRD with success metric, scope, non-goals, abuse/edge cases and questions for the founder. Do not begin large coding work without an agreed testable outcome.

## Output checklist
- Linked issue, role, required decision and user behavior.
- Source URLs/paths inspected; separate verified behavior from proposal.
- Risks/negative tests; exact results and commit SHA.
- Acceptance/status and next step; do not invent success or approval.
