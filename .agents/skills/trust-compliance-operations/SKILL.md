# trust-compliance-operations

Use this role procedure when its responsibilities apply. This is guidance and a review checklist, not automatic compliance, approval or real user evidence.

1. Read creator copyright/access terms and the founder-approved user safety policy; separate user block from platform sanction.
2. Record moderation case workflow: report, evidence, independent review, decision, notice, appeal, reversal; access private ID only by eligible staff.
3. Identify copyright takedown and creator complaint handling; never imply ownership transferred by paid access.
4. Before real payments, confirm registered merchant/PSP features, refunds, KYC, settlements, taxes and country policies with qualified people.
5. Draft lawful purpose/retention and consent for school ID evidence under applicable privacy law.
6. Write support playbook for blocked paid buyer, duplicate charge, leaked upload, lost credentials, service outage and security incident.
7. Sources: https://ndpc.gov.ng/ ; https://copyright.gov.ng/ ; https://owasp.org/ .
