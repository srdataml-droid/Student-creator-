# ux creator flows

## When to use
Use for related GitHub issues and features; this file is scoped guidance, not a granted external permission.

## Procedure
Begin with real student creator tasks: join, verify, publish original work, choose free or priced access, see profile, view content, follow, block, purchase, check earnings. Draw a short user flow including pending/empty/error/denied states. Favor simple mobile UI, tablet drawer, desktop top nav and accessibility, without imposing arbitrary palette. Prototype using existing React or editable Figma/Penpot if needed, then ask consenting testers to attempt real tasks. Implement only after acceptance criteria; verify on Android/keyboard and slow connection.

## Output checklist
- Linked issue, role, required decision and user behavior.
- Source URLs/paths inspected; separate verified behavior from proposal.
- Risks/negative tests; exact results and commit SHA.
- Acceptance/status and next step; do not invent success or approval.
